# 配置文件直接登录验证

日期：2026-10-02。运行版本：`20261002-config-login`。

## 实现

- 删除 Windows 首次配置网页、临时 HTTP 服务和网页保存配置接口。
- 启动时读取 `config.env`；管理页直接展示登录表单，账号密码、监听 IP 和端口在文件中修改，重启生效。
- Windows 单独 EXE 缺少默认文件时自动写入配置和随机密码后继续启动；既有文件不会覆盖，显式指定不存在的文件仍报告错误，原有环境变量部署方式保留。
- Windows/Linux 发布包都包含可直接使用的 `config.env`。发布配置生成独立随机密码，发布目录与本地运行目录分离，不打入开发机实际账号密码、项目数据或浏览器缓存。

## 已完成的验证

- `go test ./...` 全部通过，包括默认配置生成、已有文件保留、显式缺失文件、环境变量部署及错误路径验证。
- 生产前端构建及 Windows/Linux amd64 Go 构建通过。
- `tools/config-login-check.cjs` 在独立的临时 Windows 安装目录验证：没有配置时立即启动、直接显示登录表单、使用生成的文件凭据登录；修改文件中的账号密码和端口后重启生效，旧凭据返回 401，配置内容保持不变。
- 两个 ZIP 均包含可用配置，管理员密码已生成；Linux 内部密码也独立生成。压缩包仅包含发布文件，没有本地运行配置、项目和缓存。
- 当前 Windows 服务已用新版本重启，监听 `0.0.0.0:8888`，健康检查正常；真实浏览器使用原配置凭据直接登录成功。
- 运行目录的 `config.env`、项目数据、CPU 设置及监控采样设置的 SHA-256 与更新前完全一致。
