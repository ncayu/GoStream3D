## Overview 更新范围

删除“仅支持 CPU / 不支持 NVIDIA”的过时介绍，明确两个仓库是管理网关和 CPU/GPU 渲染器。补充 NVIDIA、Intel、WSL2 环境要求，预加载与独立会话，大屏尺寸与码率策略，Linux CPU 共享上限，NVIDIA 监控，WebRTC 逐路性能，以及成套升级和回滚说明。

尺寸最高 3840×2160 不等于稳定 4K30/60，H.264 为有损编码；驱动与 Toolkit 需要宿主机提供。逐路性能由观看浏览器报告，不能将 RTT 或解码耗时当成完整操作延迟。
