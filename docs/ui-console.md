# 云渲染控制台界面规范

## 布局与视觉

- 管理控制台使用侧边导航、顶部面包屑和状态栏、页面标题与工作区的统一结构。工作空间与系统管理分组，选中菜单清晰可见。
- 每次登录成功后进入“已创建的链接”（`/admin#links`）；空地址片段或无效片段也默认显示该页。点击创建菜单进入 `#streams`，已登录时刷新有效菜单地址保留当前页，退出后重新登录回到项目列表。
- 采用用户 2026-10-02 提供的常规后台参考图：深色侧栏、白色顶栏与内容面板、浅灰页面背景，默认蓝色操作按钮。使用纯色、细边框和轻量状态标签，去掉科技渐变、发光、大幅示意图和流程装饰。
- 桌面正文和表单以 14px 为基准，页面标题 24px，面板标题 16–18px，表单控件 38px 高，面板圆角 4–6px。侧栏 238px，顶栏 58px。控制台独立滚动，760px 以下导航改为抽屉，表格在自身容器内横向滚动。
- 外观设置提供十种简洁的强调色，使用色块选择按钮，所有配色均保留浅色内容区与深色侧栏。保留原主题 ID；选择或恢复默认只预览，点击“保存配色”后写入服务端 SQLite，并弹框反馈成功或失败。打开或登录管理后台时加载已保存的配色，未保存的预览不会保留。配色为当前服务的管理员共享设置；登录表单尚未认证时使用默认蓝色。
- 导航图标使用统一的 24×24 SVG 网格、圆角线端与 1.8px 线条，菜单中显示为 21px，置于固定 24px 槽位。创建链接使用带加号的文档，已有链接使用链环，监控使用趋势屏幕，后台设置使用对称齿轮，外观使用调色盘；选中时随文字显示白色。
- 管理控制台样式不得影响 `/Stream3D/:token` 的纯净播放端及输入转发。

## 页面逻辑

### 启动与登录

不设置“首次配置”页面。程序读取 `config.env` 中的初始管理员账号密码与监听 IP/端口，打开 `/admin` 即显示登录表单。发布包自带配置文件；Windows 单独 EXE 缺少默认文件时自动生成配置和随机密码后继续启动，既有文件不得覆盖。右上角用户菜单提供“修改账号密码”，弹框包含账号、当前密码、新密码、确认新密码；当前密码或两次新密码不匹配时显示原因。保存成功后全部后台会话失效并返回登录页，账号预填为新值，密码框清空。持久保存于会话数据目录的 `admin-account.json`，重启优先恢复已保存账号；监听 IP/端口仍在配置文件中修改后重启生效。手机上保留头像菜单和此入口。

### 创建观看链接

以“项目与页面 → 渲染配置 → 观看模式”三步组织配置，表单占满工作区宽度，不设置场景预览侧栏。资源策略来自后端，显示软件 CPU 上限、场景驻留和缓存状态。

创建页面将页面标题、资源策略、分组标题和参数的说明收进旁边的“？”提示，默认隐藏长段解释。鼠标悬停或键盘聚焦可查看，手机点击可打开；Escape、点击外部或滚动关闭。提示浮层保持在视口内，鼠标移入说明时保持显示，不触发提交或改变参数。多路参数的范围与说明随当前配额和预加载路数更新，服务器总通道数及后台设置入口仍直接显示。统一标签和输入框对齐、分组间距；原参数约束和创建行为保持不变。

创建页面不展示场景示意图、预览状态、配置摘要或生成流程侧栏。项目提交成功后进入项目列表；实际预加载状态以服务端返回为准。原始 3D 场景在服务器运行，客户端只接收画面流并回传输入。

**1 路对应 1 位用户的独立渲染会话。** 单路同一时刻支持 1 位用户，多路每位用户拥有独立画面、Worker 与输入。禁止恢复设计稿中的“多人共享场景，鼠标操作同步”语义。多路项目最大独立会话数可设 2–100，允许超过服务器总通道数；创建、编辑和服务端写入均不得按服务器配额截断或拒绝项目配额。预加载路数只能设 1–最大独立会话数，降低项目最大独立会话数时，预加载及优先保留路数自动收敛。服务端拒绝预加载超过项目配额的请求。单路的优先保留预加载路数使用下拉选择，仅可选 0、1；多路最多保留已设置的预加载路数。服务器仅配置 1 路或尚未读取总通道数时，仍可配置多路项目；服务器配额变化不调整项目配置，实际运行继续受共享通道池限制。分别显示项目配额、当前服务器总配额和已分配通道，并提供前往后台设置的入口。明确默认 3 路来自端口配置，不是 GPU 硬件检测结果，也不代表设备经实测支持的最大流畅并发。

所有项目的 CPU/GPU Worker 与预加载实例共用服务器总配额。多路创建和编辑提供“预加载路数”（1–项目配额）；新建多路表单默认 3，旧项目默认 1。预加载路数是准备目标，可超过服务器当前可用通道，实际就绪数量取决于可用通道；页面需明确这一点。项目列表显示就绪、预加载目标和加载中数量；总配额不足时明确提示部分未就绪。项目配额为 6、预加载为 3 时，前三位观看者取得已就绪实例，第 4–6 位仍可进入，但需各自等待新实例加载；这要求服务器总通道至少为 6，且没有被其他项目占满。退出后后台重新准备实例，避免复用上一位用户操作后的场景。达到项目配额或服务器总配额时，新访问显示“路数超出限额，请查看配置”，不共享其他观看者的画面与操作。提高项目配额或服务器总通道数不直接启动对应数量的 Worker，也不承诺同等数量的流畅并发。

分辨率、目标帧率、就绪标记及单路/多路参数沿用服务端契约。CPU 模式保持所选分辨率；界面说明实际帧率受场景、CPU 配额与服务器算力影响。当前 1440p 限制为 30 FPS，90/120 FPS 仅在 JPEG 传输模式下开放。

创建和编辑提供“观看页 FPS 显示”选项（开启/关闭）。项目保存 `show_fps`，旧记录缺少该字段时默认开启。项目更多操作提供“开启 FPS 显示 / 关闭 FPS 显示”，使用管理员 `PUT /api/v1/admin/sessions/:token/presentation`，允许正在观看时切换，失败保留原值并允许重试；不停止、重启实例或改变目标帧率。观看端首次连接读取公开项目状态中的 `show_fps`，JPEG 与 WebRTC 播放端在可见页面每 5 秒同步，并在获得焦点或恢复可见时立即同步；请求有超时和卸载取消。关闭后完全移除 FPS 元素，历史浏览器本地偏好不覆盖项目设置，性能诊断仍继续采样。

### 项目管理

- 展示项目数、实际运行实例数与观看人数；区分“已停止、预加载中、已预加载、运行中、预加载失败”。
- 支持名称/地址搜索、状态/渲染方式/观看模式筛选、分页和列表/卡片切换。筛选改变后回到第一页。
- 提供观看链接复制与打开、启动/停止、重新预加载、编辑及删除。正在观看的项目禁止编辑。编辑后保留原观看链接。
- 观看链接统一为当前管理页 `window.location.origin` 加 `/Stream3D/:token`，显示、复制、打开保持一致，不采用节点固定的 localhost 地址。HTTPS/本机安全环境优先使用 Clipboard API，局域网 HTTP 使用用户点击内的选区复制；两种方式均未成功时才提示失败。旧 `/v/:token` 返回 307，保留 token 和查询参数并跳转到新路径。
- 复制观看链接后，在视口顶部居中浮动提示“复制成功”或“复制失败”，成功在实际剪贴板写入完成后显示。成功提示 3 秒、失败提示 4.5 秒后自动关闭，也可手动关闭。重复点击刷新显示时间，较早请求的结果不得覆盖最新操作，不改变项目列表位置。
- 更多操作菜单在视口内定位，外部点击、滚动或 Escape 关闭。删除必须确认；失败保留弹窗并显示真实错误，可重试。编辑与删除弹窗支持键盘焦点约束。
- 列表与卡片均提供项目勾选、当前页全选和批量删除。翻页与切换视图保留选择，修改搜索或筛选条件清空选择，刷新时移除不再匹配的项目。确认弹框展示所选项目名称、数量和观看者中断提示。逐个复用原删除接口回收实例并保存数据，显示进度及成功/失败数，重试只处理未删除的项目；取消确认不发送删除请求。

播放端等待模型、独立实例或首帧时，中央显示明确提示及已等待时间，就绪后自动隐藏；未显示首帧时不转发输入。额外实例加载不能阻塞已就绪实例的接入。

### 后台设置与监控

- CPU 上限提供数值输入、滑块与预设值；采样间隔提供数值输入与预设值。默认 CPU 上限 50%，默认监控采样 30 秒；已有保存值优先展示并保留。
- 渲染通道设置允许管理员输入服务器总通道数（1–100），展示已生效配额及已分配通道（包括预加载），保存后立即生效并在重启后保留。默认值按 HTTP/CDP/UDP 端口池计算，后台保存值优先；系统按原起始端口调整端口池末端。缩小时若影响已分配的实例或端口，保留原设置、显示失败原因，不强停现有会话。
- 输入中的草稿明确显示“修改尚未保存”。右侧配置摘要只显示已生效值；保存失败不得将草稿显示为已生效，也不得隐藏此前成功读取的设置。
- CPU 已生效上限使用普通数值摘要，避免以大型装饰圆环占用工作区。项目管理不再展示流程装饰条，外观设置不再展示模拟控制台截图。
- CPU 上限与整机实时使用率分别呈现。不支持平台内 CPU 硬限制的节点明确显示不可用状态。
- CPU、内存、网络趋势沿用按需加载的 ECharts 与同一份服务端采样，不增加后台定时采样频率。切换页面或全局刷新只读取当前缓存；监控页手动刷新保持原有单次采样行为。
- 服务器通道设置为管理员配置配额，不称为 GPU 自动识别上限；实际流畅并发与场景、分辨率/帧率、CPU/GPU、显存/内存及网络有关。Windows JPEG/WebSocket 传输没有 NVENC 通道测定。通道 API 为 `GET/PUT /api/v1/admin/channels/settings`，设置持久保存在会话数据目录的 `channel-settings.json`。

## 实现与验证

`ConsoleIcon`、`CreateWorkspace`、`ProjectManager`、`PlatformSettings`、`PlatformMonitor`、`ThemeSettings` 负责各自职责；控制台视觉规则位于 `web/src/console.css`，原播放器样式保留。

`tools/simple-console-preview.cjs` 生成本机登录页及五个工作页面的桌面、移动截图，并检查统一浅色布局、十种配色和页面溢出；`tools/ui-redesign-check.cjs` 用 Playwright 拦截写入请求，验证创建、编辑、启停、删除失败重试、设置草稿/保存、分页筛选、主题持久化和移动导航。读取真实监控数据，并确认原项目与服务器资源设置未被测试修改。

`tools/copy-feedback-check.cjs` 验证剪贴板成功/失败提示和异步顺序，`tools/stream-links-check.cjs` 在局域网 HTTP 下验证原生复制粘贴、当前访问地址以及 `/Stream3D/` 路由。

截图与验证结果位于 `docs/ui-preview/`。
