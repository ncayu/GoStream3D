# 公开资料脱敏说明

公开仓库中的管理界面截图用于展示功能。真实项目名称、原始场景地址、观看地址与个人主机名使用不透明遮挡处理；截图不是可用于访问项目的配置，也不作为原始画面测量证据。

性能记录保留测试条件与测量结果，项目名称使用“示例项目 A”，场景地址使用 `https://example.com/scene`，观看令牌使用 `REDACTED_SESSION_TOKEN`。文档里的 `192.168.1.100` 仅为示例，部署时必须换成观看设备可达的服务器 IP。

## 运行诊断脚本

诊断脚本不包含真实项目名称或观看令牌。按需要在本机设置环境变量，避免将这些值提交到仓库：

```powershell
$env:GOSTREAM3D_PROBE_BASE_URL = 'http://127.0.0.1:8888'
$env:GOSTREAM3D_PROBE_TOKEN = '<从本机后台获取的项目令牌>'
$env:GOSTREAM3D_PROBE_PROJECT_NAME = '<本机选中的项目名称>'
node tools/three-stream-fps-probe.cjs 12000 3 all-active
```

会修改配置或启停项目的脚本还会核对 `GOSTREAM3D_PROBE_PROJECT_NAME`，请明确选择测试项目。需要本机配置文件和基线记录的脚本仍需按各自要求准备这些文件。预加载实时报告和 GPU 容量报告写入被 Git 忽略的 `.cache/` 目录。
